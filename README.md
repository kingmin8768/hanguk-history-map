# 산하 · 한국사 시공간 지도

시간을 따라, 땅 위의 역사를 읽는 한국사 인터랙티브 지도입니다.

**공식 자료 연표 212,574건**을 메인 화면에서 하나씩 탐색합니다. 검색어·자료군·연도 범위로 좁힌 목록 안에서 이전·다음, 슬라이더, 기록 번호, 연도 이동과 자동 재생을 사용할 수 있습니다. 직접 정리한 **지도 해설 130개**는 별도 모드에서 장소·인물과 함께 읽습니다.

| 자료 | 수록 규모 | 내용 |
| --- | ---: | --- |
| 공식 연표 메타데이터 | 212,574건 | 제공기관의 연대·제목·초록·문헌 표기·공식 자료 연결 |
| 자료군 | 19종 | 고대·근대·대한민국사, 여성사, 의료, 노동, 식생활, 장시, 전쟁, 항일운동, 화폐, 기업사 등 |
| 직접 작성한 지도 해설 | 130개 | 기원전 194년~2024년의 배경·전개·의미와 장소 |
| 주제별 읽기 | 6개 주제, 47개 해설 지점 | 문자와 지식, 교역과 생계, 수도, 전쟁과 외교, 독립운동, 헌법과 시민 |
| 인물 / 정치체·시대 개관 | 58명 / 26개 | 생애, 활동 지점, 제도와 문화, 관련 장면 |
| 도시·거점 기록 | 69묶음 | 역사적 이름과 역할의 변화 |

공식 자료 212,574건은 **서로 다른 역사 사건의 총수**가 아닙니다. 같은 사건이 서로 다른 문헌·자료군에서 기록될 수 있습니다. 기존 장면의 사건 항목 308개도 회고 기록을 포함하므로 공식 자료 수와 합산하지 않습니다. 공식 자료 중 206,203건에 초록이 있으며 나머지 6,371건은 제공 제목과 자료 연결을 보존했습니다.

**지도 표현:** 확인된 수도·유적·사건의 개략 위치를 보여줍니다. 역사적 영토 경계를 복원하는 지리 데이터베이스는 아닙니다.

## 사용

Node.js 22 이상과 Python 3이 있는 환경에서:

```bash
npm ci
npm test
npm run check
npm run build
npm run serve
```

브라우저에서 `http://localhost:3000`을 엽니다. 실행 파일은 `dist/`에 모두 들어 있습니다. 별도 빌드 과정, API 키, 서버 데이터베이스가 필요하지 않습니다. `dist/`를 정적 호스팅에 게시하면 됩니다. `file://`로 직접 열면 브라우저의 ES module/fetch 제한 때문에 동작하지 않습니다.

## 탐색 기능

- 전체 기록 / 지도 해설 모드 선택과 현재 목록의 선택 번호·총수
- 시대 선택, 이전·다음 기록, 슬라이더, 연도 입력과 정확한 기록 번호 이동
- 자동 재생과 재생 간격 선택
- 수도·사건·유적 위치, 장소 설명과 공식 자료 링크
- 옛 지명·현대 지명·사건·시대 통합 검색
- 수도 이전을 살펴보는 점선 연결 (실제 이동 경로 아님)
- 지도 이동·확대·축소·초기화
- 현재 장면 URL 공유, 밝은 화면·어두운 화면
- 반응형 화면, 키보드 조작, 출처·표현 원칙 안내
- 장면마다 배경·전개·제도·사회문화·의미를 다루는 시대 해설
- 전체 연표에서 검색어·시대·정치/전쟁/문화/사회/외교 주제 필터 조합
- 정치체와 역사적 시대의 성격·주요 도읍·변화·관련 장면 읽기
- 인물의 생애·활동·의미와 출처가 있는 활동 지점 지도
- 도시 이름과 역할의 시대별 기록
- 인물 활동 지점을 포함한 URL 복원, 원문 제목·기관으로 출처 찾기
- 21만여 공식 자료의 제목·초록 검색, 자료군·연대 범위·정렬 조합
- 전체 일치 건수, 이전·다음·첫·마지막 페이지와 페이지 번호 이동
- 원자료 날짜·역법·월일 미상·보존 메타데이터 주소·제공기관 ID 확인

상단 **역사 둘러보기**에서 전체 연표·정치체·인물·도시 기록으로 들어갑니다. 오른쪽 **시대 해설**에서 장면의 맥락을 읽고, 주요 사건과 인물 탭으로 이어갈 수 있습니다. 지도 장소의 설명에서 해당 도시의 시기별 기록을 열 수도 있습니다.

처음 열면 **전체 기록** 모드로 시작합니다. ‘검색·자료군·연도 범위’를 펼쳐 조건을 적용하고, 시대 버튼으로 연도 범위를 좁힙니다. 같은 해 여러 기록도 각각 선택됩니다. 연도 이동은 현재 조건에서 가장 가까운 수록 연도의 첫 기록을 찾으며, 같은 거리라면 이른 연도를 고릅니다. 원문 위치가 확인되지 않은 자료에 지도점을 만들지 않습니다. ‘가까운 시기의 지도 해설’은 이동한 해설의 실제 연도를 표시합니다.

상단 **자료 연표**에서는 여러 기록을 50건씩 비교하며 읽고 ‘메인에서 보기’로 선택할 수 있습니다. 메인 기록 링크는 선택한 기록 ID와 검색·자료군·연도·정렬 맥락을 복원합니다. 기존 지도 해설과 인물 경로 링크도 그대로 열립니다.

시간축의 **기록 분포**는 현재 검색 조건과 자료군에 해당하는 기록 건수를 시기별로 보여줍니다. 막대를 선택하면 해당 연도 범위로 좁혀지고, **연도 범위 해제**를 누르면 현재 검색어와 자료군을 유지한 채 전체 기간을 볼 수 있습니다. 기본 열람은 첫 50건의 작은 파일로 시작하고, 전체 검색이 필요한 시점에 압축 자료를 불러옵니다.

상단 **주제별 읽기**에서 관심 주제를 고르면 관련 지도 해설을 연대순으로 이어 읽을 수 있습니다. 각 지점에는 다음 장면과 연결되는 짧은 안내와 해당 해설의 출처가 있습니다. 공유 링크는 주제와 현재 지점을 함께 엽니다.

키보드: `←`/`→` 현재 모드의 기록 이동, `Space` 재생·일시정지, `/` 검색. 지도 장소에서 `Enter` 또는 `Space`로 설명을 엽니다.

## 역사 자료와 표현 원칙

역사 내용은 국사편찬위원회 우리역사넷, 한국학중앙연구원 한국민족문화대백과사전, 국가기록원과 관련 공식기관 문서를 바탕으로 새로 요약했습니다. 구체적인 문서와 URL은 `dist/data.js`의 `SOURCES`, 각 사건·해설·장소·인물의 `sourceIds`에 연결되어 있습니다. 같은 우리역사넷 문서의 모바일/데스크톱 URL은 하나의 출처로 합칩니다. 단순히 기관 홈페이지를 출처로 대신하지 않습니다.

- 사료의 연대·사건 설명과 현대 지리의 개략 위치를 구분합니다. 점 좌표는 수도/사건 지역의 대표점이며 당시 궁성·도시 경계를 측량한 자료가 아닙니다.
- 검증된 국경 GIS 자료가 확보되지 않아 역사적 영토 폴리곤을 그리지 않습니다. 지도 위 빈 공간은 무주지나 특정 국가의 영토를 뜻하지 않습니다.
- 해안선은 현대 Natural Earth 자료입니다. 과거 해안선·주권·행정 구획을 뜻하지 않습니다. 소규모 섬이 생략될 수 있습니다.
- 수록된 장면 사이 모든 연도의 상태를 주장하지 않습니다. 연도를 직접 입력하면 그 연도에 앞서는 가장 가까운 대표 시점을 선택하고 실제 표시 연도를 안내합니다. 슬라이더 간격은 역사적 시간 길이에 비례하지 않습니다.
- 고조선의 단군 건국 전승을 확정된 역사 연대로 처리하지 않습니다. 왕검성처럼 위치가 불확실한 곳을 정밀한 수도점으로 표시하지 않습니다.
- 신라와 발해의 병존, 고려·조선의 건국과 천도, 1945년 해방·1948년 남북 정부 수립·1953년 정전을 구분합니다. 38선과 군사분계선을 같은 경계로 그리지 않습니다.
- 1987년 이후에는 서울 올림픽, 남북한 유엔 가입, 외환위기, 남북 정상회담, 시민사회와 헌정, 2018년 선언, 2024년 문학상 수상 등의 대표 장면을 담았습니다. 매년의 모든 사건을 망라한 자료는 아닙니다.
- 인물 활동 연결선은 확인된 방문·활동 지점을 잇습니다. 출생·활동 장소를 확인하지 못한 인물은 경로를 표시하지 않습니다.
- 정치체·시대 개관에는 왕조·연맹·정부와 역사적 시기 구분을 함께 담되, 각 항목의 성격을 설명합니다. 독립적인 국가의 개수를 뜻하지 않습니다.
- 공식 자료 연표는 공공데이터포털의 **교육부 국사편찬위원회 한국역사자료 메타데이터 정보_연표(15051036)** 중 NIKH 자료입니다. 다른 전문센터의 권리 조건을 확인하지 못한 2,942행과 날짜 없는 목차 20행은 제외했습니다.
- 원자료의 분류·연대 표기는 기원전 2333년~2010년에 걸칩니다. 기원전 2333년에는 단군·기자 관련 전승이 함께 배치되며, 그해에 발생한 확정 사건이라는 의미가 아닙니다. 월일 미상의 99, 음력 L 표기, 원자료의 이상값을 임의로 고치지 않습니다.
- 자료의 역법 미표기는 양력이라는 뜻이 아닙니다. 날짜를 임의로 양력으로 환산하지 않습니다. 같은 연도 안에서는 자료 순서를 보존합니다.
- 근대사연표의 일부 개별 기사가 기관의 서비스 개편으로 사라지거나 합쳐졌습니다. 이 자료군의 연결은 정확한 개별 기사라고 주장하지 않고 공식 자료군과 원래 기사 ID를 안내합니다. 다른 자료의 현재 기사 주소도 전수 방문 검증한 것은 아닙니다.

오류를 제보할 때는 해당 장면, 문구, 근거 문서의 URL과 해당 부분을 함께 적어주세요. 날짜·정치체·수도·좌표·출처가 서로 맞는지 확인한 뒤 수정합니다. 모든 주석이 전문가의 학술 감수를 받은 것은 아닙니다.

## 파일 구조

```text
dist/
  index.html       접근 가능한 화면 구조
  styles.css       반응형 화면과 테마
  data.js          시대별 자료 조합 및 공개 데이터
  content/         고대·고려·조선·근현대 원문 기반 자료
  assemble.js      출처 중복 정리와 기존 장면 URL 유지
  catalogue.js     연표 필터·통합 검색·도시 기록
  explorer.js      정치체·인물·연표·도시 상세 탐색
  record-browser.js 메인 기록 목록·선택·캐시·비동기 이동
  main-record-view.js 메인 기록 본문·연대·출처 표시와 공통 표시 규칙
  corpus-client.js 공식 연표의 목록과 Worker 요청 관리
  corpus-query.js  전체 기록 검색·필터·페이지 인덱스
  corpus-worker.js 압축 해제·대규모 검색 처리
  corpus/          압축 공식 자료, 수록 수·출처·라이선스·해시
  model.js         연도 선택·검색·지도 투영
  app.js           지도 및 UI 상호작용
  assets/          로컬 해안선, 아이콘, 지리 자료 출처
tests/             연대·출처·수도·검색·DOM 동작 검증
scripts/           정적 배포 검증 및 지도 자료 재현
```

해안선 파일은 `python3 scripts/fetch-basemap.py`로 고정된 upstream commit에서 재현할 수 있습니다. 원본 및 결과 SHA-256은 `dist/assets/README.md`에 기록했습니다.

공식 연표는 [재현 및 출처 설명](dist/corpus/README.md)의 공개 ZIP과 `scripts/import-official-chronology.py`로 생성합니다. 원본 ZIP/CSV와 압축을 해제한 대용량 JSON은 저장소에 넣지 않습니다. `npm test`는 JavaScript/DOM/자료팩 검사와 Python importer 검사를 함께 실행합니다.

공식 연표를 처음 조회하면 약 15MiB의 압축 자료를 읽습니다. 지도 첫 화면에는 전체 자료를 올리지 않고, 큰 자료의 해제·검색은 별도 Worker에서 수행합니다. 지원되지 않는 브라우저는 공식 출처와 안내를 제공하고 지도 해설은 계속 사용할 수 있습니다.

# 메인 화면에서 전체 기록 탐색

## 요청과 원인
사용자가 메인 카운터가 36/130인 이유를 묻고 공식 연표 212,574건을 자세히 나누어 메인에서 탐색하기 원한다. 현재 메인 플레이어는 직접 작성한 지도 해설 SNAPSHOTS에만 연결되고 공식 기록은 별도 창에만 존재한다. 메인에 두 탐색 모드를 연결한다.

## 동작
- 해시 없는 첫 진입은 전체 기록 모드다. 기록을 불러오는 동안에도 지도 해설 모드로 전환할 수 있다.
- 모드 선택은 전체 기록과 지도 해설을 명시한다. 메인 카운터·이전/다음·슬라이더·재생·연도 이동은 현재 모드와 검색 조건에 연결한다.
- 공식 기록은 검색어·자료군·연도 범위로 필터한다. 시대 버튼도 실제 수록된 기록을 연대 범위로 거른다. 필터 안의 현재 번호/일치 수와 전체 자료 건수를 구분한다.
- 메인에서 기록의 원래 날짜·제목·초록·문헌 표기·제공기관 ID·공식 경로와 라이선스를 읽는다. 좌표가 없는 기록은 지도점을 만들지 않고 위치 미확인을 표시한다.
- 같은 해 여러 기록은 각각 탐색한다. 범위에 없는 연도를 요청하면 가장 가까운 수록 연도의 첫 기록을 보여주고 실제 연도를 명시한다.
- 지도 해설 130개는 기존 URL·위치·인물 경로와 함께 유지한다. 기존 장면 해시는 해설 모드로 열린다. 기록 해시는 `#records?record=ID&q=...&collection=...&from=...&to=...` 형태로 복원한다.
- 별도 자료 연표 창에서 ‘메인에서 보기’를 누르면 현재 검색 맥락의 해당 기록으로 이동한다.
- 중복 원문 기록·전승/분류 연대·99·음력/역법 미표기·1902년17월 이상값·근대사 자료군 fallback 고지는 유지한다.

## 엔진 계약
기존 corpus store에 `locate({id?,year?,q?,collection?,fromYear?,toYear?,sort?})`를 추가한다. 일치하면 `{index,total,record}`, 없으면 null이다. index는 해당 조건·정렬에서의 0기반 위치다. id가 있으면 그 기록의 위치를 찾고, year만 있으면 수치상 가장 가까운 연도의 첫 기록을 찾으며 동률은 이른 연도를 선택한다. 연도 미상은 연도 검색에서 선택하지 않는다. 같은 해 순서는 메타데이터 순서다.

## 메인 기록 컨트롤러
`createRecordBrowser({corpus,onChange,pageSize=50})`는 `init()`, `goTo(index)`, `next()`, `previous()`, `setFilters(partial)`, `seekYear(year)`, `openRecord(id,filters?)`, `dispose()` 및 읽기 전용 `state`를 제공한다.

state: `{status:'idle'|'loading'|'ready'|'error',manifest,record,index,total,filters:{q,collection,fromYear,toYear,sort},error}`. 공개 상태는 사본을 제공한다. 50개씩 캐시하고 그 안에서 이동할 때 재조회하지 않는다. 필터 변경은 첫 기록으로 돌아간다. 빠른 이동/필터/해시 전환의 이전 응답이 최신 선택을 덮어쓰지 않는다. 잘못된 번호·0년·불가능 범위는 안전하게 처리한다. openRecord의 filters는 기본 조건과 합성한 새 맥락이다. 전체 원문 데이터는 Worker에만 둔다.

## 검증
212,574를 메인 전체 기록 카운터에 표시하고 같은 해의 서로 다른 기록이 다음/이전으로 열린다. 슬라이더·번호 이동·시대/자료군/검색 필터·연도 점프·빈 결과·실패 재시도·마지막 재생 정지·빠른 비동기 이동·기록 URL 복원·해설 복귀·확인되지 않은 좌표 비표시를 검사한다. 제거한 선택적 참고 표기를 다시 추가하지 않는다.
